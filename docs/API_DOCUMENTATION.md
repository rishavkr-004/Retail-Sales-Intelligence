# Retail Sales Intelligence API Documentation

## Project Overview

The Retail Sales Intelligence API provides machine learning services for sales prediction, customer return prediction, customer segmentation, and sales forecasting.

## Deployment Information

- Framework: Flask
- Programming Language: Python
- ML Library: Scikit-learn
- Model Serialization: Joblib
- Production Server: Gunicorn
- Hosting Platform: Render

## Base URL

https://retail-sales-intelligence-b5qc.onrender.com

---

## 1. Health Check

**Endpoint:** `GET /health`

Checks whether the API is running.

Example response:

```json
{
  "service": "Retail Sales Intelligence API",
  "status": "healthy"
}
```

## 2. Sales Prediction

**Endpoint:** `POST /predict-sales`

Predicts sales using the trained machine learning model.

### Request body

```json
{
  "Quantity": 3,
  "Discount": 0.1,
  "Shipping Days": 4,
  "Order Year": 2026,
  "Order Month": 11,
  "Order Weekday": 3,
  "Category": "Technology",
  "Sub-Category": "Phones",
  "Region": "West",
  "Segment": "Consumer"
}
```

### Example response

```json
{
  "predicted_sales": 288.12
}
```

## 3. Customer Return Prediction

**Endpoint:** `POST /predict-return`

Predicts the probability that a customer will return.

### Request body

```json
{
  "Recency": 30,
  "Frequency": 5,
  "Monetary": 2500,
  "Total_Quantity": 12,
  "Average_Discount": 0.1,
  "Average_Order_Value": 500,
  "Customer_Lifespan": 180
}
```

### Example response

```json
{
  "return_probability": 0.2851,
  "returned_prediction": 0
}
```

## 4. Customer Segmentation

**Endpoint:** `POST /segment-customer`

Assigns a customer to an RFM cluster.

### Request body

```json
{
  "Recency": 30,
  "Frequency": 5,
  "Monetary": 2500
}
```

### Example response

```json
{
  "cluster": 0
}
```

Note: Cluster numbers are machine-generated labels. Their business meaning should be determined from the customer segment analysis.

## 5. Sales Forecasting

**Endpoint:** `GET /forecast-sales`

Returns the next six forecast periods available from the trained forecasting model.

### Example response

```json
{
  "forecast": [
    {
      "month": "2018-01",
      "forecast_sales": 13350.21
    }
  ],
  "forecast_periods": 6
}
```

The actual API response contains all six forecast records.

---

## Error Handling

The API may return an error response when:
- Required input fields are missing.
- Input values have invalid formats.
- A model file cannot be loaded.
- An internal server error occurs.

Always check the HTTP status code and response body.

## Important Notes

- Predictions are generated by trained machine learning models.
- Forecasts depend on the historical data used during training.
- The current forecasting dataset ends in 2018, so the returned forecast dates are historical relative to 2026.
- This API is deployed on Render. Free instances may take extra time to respond after inactivity.
